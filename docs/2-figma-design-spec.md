## 3. МИКРО-ВЗАИМОДЕЙСТВИЯ (АНИМАЦИИ)

### 3.1 Hover-эффекты
- Карточки курсов: подъем на 4px + тень
- Кнопки: изменение цвета на 10% темнее
- Чекбоксы: плавная анимация галочки

### 3.2 Переходы
- Переключение табов: fade через 0.2s
- Drag-and-drop: плавное перемещение
- Загрузка: скелетон-экраны

### 3.3 Прогресс-анимации
- Заполнение прогресс-бара: плавное увеличение
- Получение XP: всплывающее +1
- Повышение уровня: конфетти
